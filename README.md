# tm-product-portfolio

Personal portfolio site — built to showcase my work as a Senior PM across automotive, telecom, and public health projects.

Live at: https://tm-product-portfolio.vercel.app

---

## What's this?

This is the codebase behind my portfolio. It's a single-page React app with case studies, AI use cases, a GitHub projects section, and some writing about how I approach product work.

Built with React, TypeScript, Vite, and shadcn-ui. Animated with Framer Motion. Dark mode included.

## Structure

Case studies and project data live in `src/data/`. Sections of the page are in `src/components/sections/`. Pages are in `src/pages/`.

---

Deployed on Vercel.
